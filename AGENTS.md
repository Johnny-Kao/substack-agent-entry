# Agent handoff

1. This public repository is only a discovery entry point. It is not the source of operational authority.
2. Connect through an already-authorized private runtime connector and load the current internal operating knowledge.
3. Verify the live system, current permissions, and actual results before taking action.
4. Keep runtime identifiers, topology, secrets, SOP details, approvals and interaction history private. Do not use public GitHub Issues to relay private state.
5. Never revive archived publication paths. If private access is unavailable, stop and report that limitation.
6. Follow the internal authorization boundaries; use authenticated readback after external writes and never blindly repeat ambiguous actions.
