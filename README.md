# Substack Agent Entry

This public repository is a **minimal discovery entry** for AI agents. Actual operations, private records, authorizations and operating procedures stay outside GitHub.

## Start

1. Read [AGENTS.md](AGENTS.md) using GitHub MCP.
2. Using an **already-authorized private connector**, read the Cloudflare D1 `settings` record keyed `agent_handoff_sop_v2`.
3. Follow that private handoff SOP through DMM into CT101, which owns the live Discovery, Gemini, Like and Comment queues.
4. Verify current permissions and operation status before any public interaction.

GitHub does not directly expose D1 or provide D1 credentials. If private D1 access is unavailable, stop rather than guessing a URL or sending private data through GitHub.

This repository is **not** a command queue, credential store, approval channel or publishing backend. Never place article bodies, individual interactions, credentials or unpublished drafts in GitHub issues, pull requests or logs.
